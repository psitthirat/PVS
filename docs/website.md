# Study website: edit, build and publish

The website follows the author’s October report in two parts: overall Thai findings with international comparisons, and usual private-hospital users. It has 13 chapters, reading/presentation/exploration modes, light and dark themes, and 32 downloadable charts. The site is static and self-contained, with local fonts and no analytics or external runtime dependencies.

## Where to edit

Edit the source on the left, then run the command on the right. **Do not edit `site/assets/` by hand**: everything there is regenerated by `python -m pvs story`. Its `sources/`, `fonts/` and `geography/` folders are published copies of `content/`.

| To change | Edit | Then run |
| --- | --- | --- |
| Page layout, styling, interaction | `site/index.html`, `site/styles.css`, `site/app.js` | `python -m pvs.web_assets` |
| Chapter text, findings and chapter order | `src/pvs/story_content.py` | `python -m pvs story` |
| Subgroup charts and shared chart style | `src/pvs/storytelling.py` | `python -m pvs story` |
| National and international charts | `src/pvs/story_overview.py` | `python -m pvs story` |
| Maps | `src/pvs/story_maps.py` | `python -m pvs story` |
| Original-style figures 4–6 and the private-user route chart | `src/pvs/report_figures.py` | `python -m pvs story` |
| National aggregates | `content/national/` (regenerate with `python -m pvs.national`; see below) | `python -m pvs story` |
| International values and source records | `content/international/` | `python -m pvs story` |
| Map geometry, fonts, recall confirmation | `content/geography/`, `content/fonts/`, `content/questionnaire/` | `python -m pvs story` |
| Report request record (checksum, contact) | `content/report-release.json` | `python -m pvs story` |
| Subgroup estimates | `results/2026-09/tables/` is a frozen release; do not edit | — |

`python -m pvs.web_assets` only refreshes the content-hashed CSS/JavaScript URLs in `index.html`, without redrawing charts. The public verifier rejects stale asset versions.

The story build reads public aggregate files only. It does not load respondent-level data, does not modify the frozen September release, and never overwrites the author’s report. Rebuilding unchanged inputs produces byte-identical files, so `git diff` after a build shows only real changes.

## Build, preview and check

```bash
python -m pvs story
python3 tools/serve_site.py          # http://127.0.0.1:8768, browser caching disabled
```

You can also open `site/index.html` directly. Before committing, run the public checks; none need private inputs:

```bash
python -m unittest discover -s tests -v
python tools/verify_release.py       # frozen September release and clean notebook
python tools/verify_comparisons.py   # international/Thai joins and source copies
python tools/verify_story.py         # website data, charts, ZIP and asset versions
python tools/verify_public_files.py  # no private paths, identifiers or credentials
```

`verify_public_files.py` reads tracked and non-ignored untracked files and leaves the Git index unchanged.

## Publish

The site is hosted from the public repository `psitthirat/PVS` at <https://psitthirat.github.io/PVS/>. Publishing is deliberate: a commit or push alone does not deploy.

1. Commit and push the reviewed files to `main`.
2. In GitHub Actions, run **Publish PVS dashboard** (`.github/workflows/pages.yml`), or run `gh workflow run pages.yml`. It repeats the four public checks, then uploads only `site/`. It does not rebuild charts or read private inputs.
3. Check the deployed page: both themes, the two study parts, presentation navigation, PNG/SVG/CSV downloads and the report email link.

Pages must use **GitHub Actions** as its source (Settings → Pages). The workflow follows [GitHub’s custom Pages workflow documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Full report requests

The reviewed Thai report is supplied by email request to [peerasit.sit@mahidol.ac.th](mailto:peerasit.sit@mahidol.ac.th). The site opens a prepared email draft; it does not send a message or collect contact details. No DOCX is packaged in `site/` or the chart ZIP, and the former `assets/reports/pvs-thailand-study.docx` URL is removed on every build.

[`content/report-release.json`](../content/report-release.json) records the reviewed report checksum, audit scope and contact. When the private author report (`output/reports/ผลการสำรวจ_20261001.docx`) is present, the build refuses a file whose checksum differs from that record. Public clones use the record without needing the DOCX.

### Recheck the author report (private inputs)

```bash
python tools/audit_current_report.py
```

This requires `output/analysis_frame.pkl` and the author-managed October DOCX. It recomputes descriptive values, Pearson or Monte Carlo tests under the printed method, and the four overall model tables (`src/pvs/report_models.py`). It checks September contrasts against approved CSVs, reruns segmentation models, and traces numeric result prose to its sources (`tools/review_report_claims.py`). Output: `output/reports/ตรวจซ้ำก่อนเผยแพร่_ผลการสำรวจ_20261001.xlsx`. It never edits the DOCX. After future author edits, rerun the audit and review its findings before updating the release record.

## Charts and downloads

Each chart is available as a 300-dpi PNG and a vector SVG with outlined text. Downloads have no overall title or narrative caption; axes, metric labels, legends, values, the institutional copyright and required map attribution remain. A second SVG with the same data and geometry supplies the dark website display; downloads keep a white background for documents and slides. Figures 4–6 retain their original data colors and panel geometry in both themes, and their white PNGs are identical to the reviewed report images.

The chart ZIP contains print PNG/SVG files, `story.json` with captions and source metadata, relevant aggregate CSVs and geographic source notices. When reusing a graphic, keep its denominator, recall period and interpretation notes with it.

Motion is limited to the opening proportions, brief panel transitions and one-time reveals; reduced-motion preferences disable them. The opening shows 2,017 dots with three verified aggregate proportions. It is a proportion display, not respondent-level data.

## Data notes

**National findings.** `content/national/national_summary.csv` restores the original report’s full-sample demographics, health, prevention, service use, usual-source coverage, confidence and system ratings, with municipal/non-municipal and usual-source/no-usual-source comparisons. These are descriptive, unweighted associations. With the trusted local prepared frame, regenerate them with:

```bash
python -m pvs.national --frame output/analysis_frame.pkl --out content/national
```

The Q40 maternity, child, chronic-care and mental-health ratings are mapped explicitly from the canonical Thai response labels; unexpected labels are rejected and respondents who cannot evaluate a service are excluded (valid denominators 1,650; 1,702; 1,787; 1,648). See the [report notes](report-editorial-notes.md).

**International comparisons.** 223 published foreign and pooled values across 14 indicators, plus separately joined Thai estimates. Unmet need uses Croke et al.’s 14-country Table 1; confidence, quality and system opinions use Kruk et al.’s 15-country Figures 2–3. Published totals are kept as reported, not recomputed or pooled with Thailand. Argentina’s estimate concerns **Mendoza Province only**, so its national polygon stays grey and a locator marks Mendoza. Thailand is outlined and hatched because it represents an unweighted achieved sample in 13 selected provinces. Neither maps nor bar charts establish a comparable national ranking.

**Recall periods.** Thai Q27 preventive services, Q29 unmet need and Q31 financial hardship refer to the past 12 months, confirmed by the researcher against the original questionnaire on 1 October 2026 ([record](../content/questionnaire/recall-confirmation.json)). Sampling, weighting, fieldwork timing and context still differ between countries.

**Thailand map.** It shows achieved sample counts in 13 provinces, one per health region; the other 64 provinces are grey. It does not estimate outcomes across Thailand.

**Licences.** Thailand boundaries use geoBoundaries/OpenStreetMap under ODbL 1.0; world geometry and the Mendoza locator come from public-domain Natural Earth. Sarabun and Prompt carry the SIL Open Font License. These licences are separate from the project copyright and the MIT software licence.
